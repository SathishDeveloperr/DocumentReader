# Markdown to Voice

A quick demo file to check that the **parser**, the *player* and the voice
picker all behave. Visit <https://example.com> for nothing in particular.

## Why listen instead of read

Reading long notes on a small screen is tiring. Listening lets you:

- walk around while you review
- catch awkward phrasing you would skim past
- get through a backlog of `README` files

> Audio is a different sense for the same words.

### A deeper heading

This heading is level three, so it stays inside the same track but still gets
spoken aloud.
